# Customer Support Ticket Priority Prediction and Automated Assignment System Using Agentforce

A Salesforce project that analyzes a customer's latest support ticket, classifies it as High, Medium or Low priority, assigns a support level, and creates an urgent task for High-priority tickets. Users interact with it through an Agentforce subagent.
